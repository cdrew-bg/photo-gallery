# Gallery context

## Glossary

- **Image**: an original photo stored in the public image repo as `images/<id>.<ext>`, where
  `id` is the first 12 hex chars of the content SHA-256. Content-addressed, so its URL never
  changes.
- **Thumb**: the 400px-wide webp preview of an Image, at `thumbs/<id>.webp`, generated by ingest.
- **Manifest**: `manifest.json` in the image repo — the single source of truth the app renders
  from: id, original filename, extension, content type, dimensions, byte size, `takenAt`
  (EXIF DateTimeOriginal, falling back to file mtime), sorted newest first.
- **Gate**: the client-side shared-password screen. Cosmetic access control only (see ADR 0002);
  unlock is remembered per browser via localStorage.
- **Ingest**: running `scripts/ingest.mjs` against a folder of photos to populate the image repo
  and regenerate the Manifest. The only way images enter the system.
- **Viewer**: anyone who has been given the shared password. There is no per-user identity.

## Boundaries

- The app repo (this repo) deploys to GitHub Pages; the image repo is pure storage.
- The app never writes to the image repo; only Ingest does.
